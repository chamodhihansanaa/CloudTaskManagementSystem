# 🌐 Cloud Task Management System (Frontend)

A modern and responsive **Task Management System Frontend** built using React. This application allows users to manage tasks efficiently with a clean UI and seamless user experience.

---

## 🚀 Features

* 🔐 User Authentication UI (Login/Register)
* 📋 Task Management Interface (Create, Update, Delete Tasks)
* 📊 Dashboard with task overview
* 🎨 Responsive UI (Mobile + Desktop)
* ⚡ Fast and dynamic React components
* 🌐 API integration ready (Backend Microservices)

---

## 🛠️ Tech Stack

* ⚛️ React.js
* 🟦 TypeScript (if used)
* 🎨 Tailwind CSS / CSS / Bootstrap
* 🔗 Axios (API calls)
* 🌍 REST API Integration

---

## 📁 Project Structure

```bash
src/
│
├── components/     # Reusable UI components
├── pages/          # Main pages (Login, Dashboard, Tasks)
├── services/       # API calls
├── assets/         # Images & styles
└── App.js / App.tsx
```

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/chamodhihansanaa/CloudTaskManagementSystem.git
cd CloudTaskManagementSystem
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the project

```bash
npm start
```

👉 App will run on:

```
http://localhost:3000
```

---

## 🔗 Backend Integration

This frontend is designed to connect with a **Microservices Backend**:

* 👤 User Service
* 📋 Task Service
* 🔐 Auth Service
* 🌐 API Gateway

👉 Example API:

```
http://localhost:8080/tasks
http://localhost:8080/users
```
